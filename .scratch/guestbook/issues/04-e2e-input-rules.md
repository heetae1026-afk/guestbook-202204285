# 04: 입력 규칙과 서버 검증 E2E

**What to build:** 브라우저의 입력 검증을 우회해도 서버가 같은 입력 규칙을 적용하는지 E2E로 검증한다. 입력 규칙은 이름 1–20자, 메시지 1–500자, 글 비밀번호 4–64자이며, 앞뒤 공백을 뺀 뒤 문자 단위로 센다. 거부될 때는 한국어 안내가 보이고, 입력한 이름과 메시지는 유지되어야 한다.

참고: docs/specs/0001-guestbook.md (User Stories 3–9, 35, 50; Implementation Decisions의 검증 규칙)

**Blocked by:** 01 (E2E 테스트 기반 구축 + 작성·조회 시나리오)

**Status:** done

- [x] 브라우저 입력 검증(`required`, 길이 제한 속성)을 끈 상태에서 폼을 제출해, 서버 검증이 실제로 거부하는지 확인한다.
- [x] 빈 이름, 빈 메시지, 공백만 입력한 이름·메시지는 각각 알맞은 안내와 함께 거부된다.
- [x] 21자 이름, 501자 메시지, 3자 글 비밀번호는 거부된다.
- [x] 이모지 등이 섞인 20자 이름과 500자 메시지는 받아들여진다. 글자 수를 UTF-16 단위가 아니라 문자 단위로 세는지 확인하는 항목이다.
- [x] 거부되었을 때 입력한 이름과 메시지가 폼에 그대로 남는다.
- [x] 수정할 때도 빈 메시지와 501자 메시지는 거부되고, 원래 데이터는 바뀌지 않는다.
- [x] 거부된 입력으로는 방명록 글이 하나도 만들어지지 않는다(새로고침 뒤 목록으로 확인).
