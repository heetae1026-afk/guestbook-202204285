# 02: 수정 시나리오 E2E

**What to build:** 글쓴이가 글 비밀번호로 자기 방명록 글의 메시지를 수정하는 흐름을 E2E로 검증한다. 틀린 글 비밀번호는 거부되고 그 사실이 안내되어야 한다.

참고: docs/specs/0001-guestbook.md (User Stories 27–40)

**Blocked by:** 01 (E2E 테스트 기반 구축 + 작성·조회 시나리오)

**Status:** done

- [x] [수정]을 누르면 그 방명록 글 자리에 현재 메시지가 채워진 수정 폼이 열린다.
- [x] 틀린 글 비밀번호로 제출하면 "글 비밀번호가 일치하지 않습니다. 수정되지 않았습니다."가 그 글 자리에 보이고, 고쳐 쓴 메시지는 입력란에 그대로 남는다.
- [x] 위 경우 새로고침하면 원래 메시지가 그대로 보인다(데이터가 바뀌지 않음).
- [x] 다른 방명록 글의 글 비밀번호로 제출해도 똑같이 거부된다.
- [x] 맞는 글 비밀번호로 제출하면 메시지가 바뀌고, "(수정됨)"이 표시되고, 수정 폼이 닫힌다.
- [x] 수정한 뒤에도 작성 시각은 수정 전과 같다.
- [x] 오류가 난 상태에서 [취소]를 눌렀다가 수정 폼을 다시 열면 이전 오류 안내가 보이지 않는다.
- [x] 이름은 수정 폼에서 바꿀 수 없다.
