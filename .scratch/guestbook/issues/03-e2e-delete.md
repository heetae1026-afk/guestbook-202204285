# 03: 삭제 시나리오 E2E

**What to build:** 글쓴이가 글 비밀번호로 자기 방명록 글을 삭제하는 흐름을 E2E로 검증한다. 틀린 글 비밀번호는 거부되고 그 사실이 안내되어야 하며, 삭제는 영구적이다.

참고: docs/specs/0001-guestbook.md (User Stories 41–47)

**Blocked by:** 01 (E2E 테스트 기반 구축 + 작성·조회 시나리오)

**Status:** done

- [x] [삭제]를 누르면 그 방명록 글 자리에 글 비밀번호 입력란과 [삭제 확인] 버튼이 나타난다. 이 단계에서는 아직 아무것도 삭제되지 않는다.
- [x] 다른 방명록 글의 글 비밀번호로 제출하면 "글 비밀번호가 일치하지 않습니다. 삭제되지 않았습니다."가 그 글 자리에 보이고, 새로고침 뒤에도 글이 남아 있다.
- [x] 맞는 글 비밀번호로 제출하면 방명록 글이 목록에서 사라지고, 새로고침 뒤에도 흔적(자리 표시 등) 없이 없다.
- [x] [취소]를 누르면 입력란이 닫히고 방명록 글은 그대로 남는다.
