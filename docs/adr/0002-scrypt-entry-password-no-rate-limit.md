# 글 비밀번호는 scrypt 해시로 저장하고, 무차별 대입 방어는 범위 밖으로 둔다

글 비밀번호는 Node 내장 `crypto.scrypt`(글마다 무작위 salt)로 해시해 저장하고 timing-safe 비교로 검증한다. bcrypt/argon2는 네이티브 빌드 부담 때문에 택하지 않았다. 틀린 비밀번호 반복 시도에 대한 레이트리밋·잠금은 의도적으로 구현하지 않는다: 미니 방명록이라 피해 규모가 작고, 서버리스 환경에서는 메모리 기반 제한이 동작하지 않으며 DB/외부 서비스 기반 제한은 복잡도 대비 이득이 적다고 판단했다.

## Consequences

- 짧은 글 비밀번호(예: 4자리 숫자)는 무차별 대입으로 뚫릴 수 있다. 폼에서 쉬운 비밀번호를 피하라고 안내하는 것으로 대신한다.
- 저장된 해시 형식(`scrypt$salt$hash`)을 바꾸려면 기존 글과의 호환 처리가 필요하다.
